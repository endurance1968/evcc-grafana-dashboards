# Import SMA Energy Balance Into EVCC/VictoriaMetrics

This page describes the optional import of SMA energy-balance monthly files into VictoriaMetrics. The import is intended for historic years where no EVCC data exists. It deliberately creates EVCC-compatible daily rollups, not EVCC raw metrics.

## Purpose

SMA energy-balance files contain daily system totals such as PV generation, home consumption, grid import, feed-in, and battery energy. They can fill old years in the `Month`, `Year`, and `All-time` dashboards even though EVCC did not yet write raw data to VictoriaMetrics at that time.

They cannot recreate `Today` time series, loadpoints, vehicles, individual consumers, SOC min/max, or 15-minute views. The files contain daily energy only, not power curves.

## Input Format

Supported SMA files are named like this:

```text
Energiebilanz_YYYY_MM.csv
```

The files contain daily rows and columns such as:

- `Gesamtverbrauch / Zähleränderung [kWh]`
- `Direktverbrauch / Zähleränderung [kWh]`
- `Batterieentladung / Zähleränderung [kWh]`
- `Netzbezug / Zähleränderung [kWh]`
- `PV-Erzeugung / Zähleränderung [kWh]`
- `Netzeinspeisung / Zähleränderung [kWh]`
- `Batterieladung / Zähleränderung [kWh]`

Decimal comma and Excel formula dates such as `="01.06.2024"` are supported. A yearly summary file such as `Energiebilanz_2014_2025.csv` is ignored by the daily importer.

## Generated Metrics

The importer writes daily values with `source="sma_energy_balance"` and the usual `local_year` / `local_month` labels:

```text
evcc_home_energy_daily_wh
evcc_pv_energy_daily_wh
evcc_grid_import_daily_wh
evcc_grid_export_daily_wh
evcc_battery_charge_daily_wh
evcc_battery_discharge_daily_wh
evcc_pv_direct_consumption_daily_wh
```

This makes historic SMA daily values behave like EVCC rollups for the long-range dashboards. The source remains visible and can be replaced selectively.

## Dry Run

```bash
python3 scripts/helper/import-sma-energy-balance.py \
  --input-dir data/private/sma-portal/Energie/Monate \
  --start 2015-01-01 \
  --end 2024-07-01
```

The dry run prints the range, series, samples, and totals per energy type. It does not write anything.

## Write To VictoriaMetrics

Write only to a target or test VM, never to a production read-only instance:

```bash
python3 scripts/helper/import-sma-energy-balance.py \
  --vm-base-url http://localhost:8428 \
  --input-dir data/private/sma-portal/Energie/Monate \
  --start 2015-01-01 \
  --end 2024-07-01 \
  --write --replace
```

`--replace` deletes only series generated by this importer with `source="sma_energy_balance"`. Other EVCC rollups stay untouched.

## Imported Data Scope

This script imports only historic daily energy for total PV, home, grid, and battery. It does not import per-source PV yields and does not create power time series.

For historic years without EVCC data, this import intentionally creates EVCC-compatible daily rollups. For transition periods with real EVCC rollups, restrict the import range so SMA and EVCC energy are not counted twice in the same dashboards.
