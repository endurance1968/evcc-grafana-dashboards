# TAB Dashboard Screenshots

Englische Version: [README_EN.md](./README_EN.md).

Diese Screenshots dokumentieren die empfohlenen Grafana-13-TAB-Dashboards.

## Erwartung

Screenshots sollen zeigen:

- Dashboard-Titel
- Tab-Navigation, wenn vorhanden
- zentrale Panels mit Daten
- keine offensichtlichen No-Data- oder Query-Fehler, sofern Daten im Testzeitraum vorhanden sind

## Typische Konfiguration

```env
DASHBOARD_LANGUAGE=de
DASHBOARD_VARIANT=gen
```

## Pflege

Vor einer neuen Screenshot-Serie alte Dateien entfernen und danach die Dokumentation aktualisieren. Die Screenshots sollen die reale Nutzeransicht nachvollziehbar machen, nicht nur einzelne Panels isoliert zeigen.
